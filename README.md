# Awesome OSINT [![Awesome](https://cdn.rawgit.com/sindresorhus/awesome/d7305f38d29fed78fa85652e3a63e154dd8e8829/media/badge.svg)](https://github.com/sindresorhus/awesome)

[<img src="https://github.com/jivoi/awesome-osint/raw/master/osint_logo.png" align="right" width="100">](https://github.com/jivoi/awesome-osint)

一份精选的、极其出色的开源情报工具与资源清单。
[开源情报 (OSINT)](https://en.wikipedia.org/wiki/Open-source_intelligence)是从公开来源收集的情报。
在情报界（IC）中，“open”一词指的是公开的、可公开获取的来源（与隐蔽或秘密来源相对）。

本清单旨在帮助所有从事网络威胁情报（CTI）、威胁狩猎或开源情报的人士，从初学者到高级用户皆可受益。

*Google Dorks 工具*

* [DorkGenius](https://dorkgenius.com/) - DorkGenius 是用于为 Google、Bing 和 DuckDuckGo 生成自定义搜索查询的终极工具。- 我们的前沿应用利用 AI 的力量帮助您创建高级搜索查询，从而在网上准确找到您要找的内容。
* [DorkGPT](https://www.dorkgpt.com/) - 使用 AI 生成 Google Dork。
* [Google Hacking Database (GHDB)](https://www.exploit-db.com/google-hacking-database) - GHDB 是搜索查询（我们称之为 Dork）的索引，用于查找公开信息，面向渗透测试人员和安全研究人员。
* [SearchDorks](https://kriztalz.sh/search-dorks/) - 使用 AI 生成搜索引擎（Google、FOFA、Shodan、Censys、ZoomEye）Dork。
